# VocabQuest

Responsive English vocabulary learning web app built with Next.js.

## MVP
- Topic dashboard
- Vocabulary flashcards
- Meaning Rush / Quick Match / Fill the Gap entry points
- Review screen
- Responsive desktop and mobile navigation
- Local vocabulary data ready to be replaced by Firestore

## Run
```bash
npm install
npm run dev
```

## Next phase
